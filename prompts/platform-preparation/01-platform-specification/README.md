# Step 1 Prompt Package

This package implements Step 1 of the Platform Preparation Protocol as a questionnaire-driven audit.

Files:
- `platform-audit-prompt.md` — execution instructions.
- `platform-audit-questionnaire.md` — mandatory field/acquisition contract.
- `platform-audit-report-template.md` — human report rendering contract.

Run the same package unprivileged and privileged to compare evidence availability. A privileged run is still read-only: privilege expands observation only and does not authorize tuning or mutation.
